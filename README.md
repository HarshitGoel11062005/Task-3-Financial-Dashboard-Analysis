# 💼 Financial Performance Dashboard – Power BI

### 📊 Project by: Harshit Goel

---

## 🧠 Overview
This Power BI project analyzes company financial data using the **Microsoft Financial Dataset**.  
It provides an interactive view of **Sales, Profit, and Profit Margin** across different countries, segments, and products.

---

## 🎯 Objectives
- To visualize and track key financial performance metrics.  
- To identify top-performing regions and products.  
- To derive actionable insights for better business decisions.

---

## 🧰 Tools & Technologies
- **Power BI Desktop**
- **Excel (Data Cleaning)**
- **DAX (for KPI calculations)**

---

## 📂 Dataset
**Source:** Microsoft Excel Financial Sample  
**Columns:**  
- Country  
- Segment  
- Product  
- Units Sold  
- Sales  
- Profit  
- Profit Margin %

---

## 📈 Dashboard Features
### 1. **Sales Overview**
- Sales by Country (Treemap)
- Yearly Sales Trend
- Segment-wise Comparison

### 2. **Profitability Analysis**
- Profit by Product
- Average Profit Margin %
- Top 5 Products by Profit

### 3. **Performance Summary**
- Combined KPIs (Sales, Profit, Margin)
- Interactive filters (Country, Segment)

---

## 💡 Key Insights
- The **United States** recorded the highest sales.  
- **Paseo** was the most profitable product.  
- The **Government segment** achieved the highest average profit margin.  

---

## 📊 KPIs
| Metric | Description |
|--------|--------------|
| **Total Sales** | Total revenue generated |
| **Total Profit** | Net profit after costs |
| **Avg. Profit Margin %** | Average profit per sale |

## 🚀 How to Use
1. Open `Financial_Dashboard_Harshit.pbix` in Power BI Desktop.
